# Product decisions and copy

Settled decisions that `PRODUCT.md` and `DESIGN.md` have no room for. Read before naming, wording or scoping work.

## Name

"Ember" is final. The packages stay scoped (`@eduard-cc/ember`, `@eduard-cc/ember-server`) so they are never confused with Ember.js.

## Watch and health integration

Nothing is built, and it stays an open decision (`PRODUCT.md`). If it is built, it must be fully automatic after setup and must never duplicate sessions or overwrite recorded sets. The route researched so far is Gadgetbridge.

## Copy

- Confirmations name the affected item and the immediate consequence, state only real risks and offer a safe cancel. They never reassure about history, records or sync.
- Public descriptions of the app say what it does, never what it lacks.
