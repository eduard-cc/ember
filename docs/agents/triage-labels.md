# Triage labels

The skills name five triage roles. Each maps to a Linear label of the same name, already defined for the Ember project's team.

| Role              | Linear label      | Meaning                                    |
| ----------------- | ----------------- | ------------------------------------------ |
| `needs-triage`    | `needs-triage`    | Needs evaluating before anyone works on it |
| `needs-info`      | `needs-info`      | Waiting for more information               |
| `ready-for-agent` | `ready-for-agent` | Fully specified; an agent can pick it up   |
| `ready-for-human` | `ready-for-human` | Needs a human to implement it              |
| `wontfix`         | `wontfix`         | Will not be actioned                       |
